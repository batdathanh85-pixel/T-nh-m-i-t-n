# Tính Tôn Mái
Ứng dụng PWA độc lập, tối ưu cho điện thoại.

## Dùng thử
Mở index.html hoặc tải toàn bộ thư mục lên hosting HTTPS (GitHub Pages).

## Cài Android
Mở URL HTTPS bằng Chrome → menu ⋮ → Cài đặt ứng dụng / Thêm vào màn hình chính.

## Chức năng bản đầu
- Tính số tấm theo khổ phủ hữu dụng.
- Tính chiều cao hai đầu tấm theo độ dốc mái.
- Chọn hướng lợp và loại tôn.
- Chọn nhiều tấm và nhóm ghép phôi thủ công.

Lưu ý: ghép phôi hiện mới là nhóm danh sách, chưa có sơ đồ tự động tối ưu nesting. Đối chiếu thực tế và hướng chồng mí trước khi cắt.
